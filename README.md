# UStoat - A client for [stoat.chat](https://stoat.chat) writen in python
UStoat (UniversalStoat) is a minimalistic stoat client (with multi platform support) completly writen in python and with the use of the great [pygame-ce](https://pyga.me/) libary.

## Features

* caching system (only runtime, this makes sure that we never hit API limits or stress the API)
* Compact minimalistic interface
* Notification sound
* Support for converted revite themes (the themes are wip)
* Simple login
* UStoat RPC (port 19200, deactivated in release version)

## Info

* I use Nuitka and PyInstaller (Windows version) for packing. (you can find the client download in the releases page)
